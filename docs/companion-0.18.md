# 0.18 陪伴表达调整

本批调整普通聊天、主动关怀和共同话题的系统提示词，不增加对话模式、意图分类调用或模型路由。现有角色文件不被覆盖，用户自己的角色设定继续生效。发布与部署状态以本批发布记录为准。

## 普通聊天

- 先回应实际说的话。短消息允许短回复，完整求助给出需要的细节；不把所有求助缩成一个小步骤，也不再请求已经给出的帮助授权。
- 问题只在缺失信息会实质影响回应或自然接话时出现。陈述、反应和自然结束可以独立成立，不固定以问题、帮助邀约或任务收尾。
- 不重复复述整条消息来表示理解，不把每次倾诉变成情绪诊断、积极解释或建议清单。避免复用上一轮的开头、安慰和追问。
- 跟随当前话题。旧活动、事件和记忆仅在有用时自然引用；不借记忆展示熟悉程度，不追问已经提供的信息，不把简短回应或暂停回复解释成拒绝，也不要求用户给予注意。

## 主动关怀与话题

主动关怀利用已有近期问候参考，避开重复的主题、开头、安慰和问题，而不只是替换同义词。普通问候可以只是一句简短的话，不自动变成健康问卷、励志劝说或回复要求；获准事件不代表知道事件结果。

共同话题继续允许模型选择零分享。正文缺少具体价值、重复、宣传性强或已过时可以保持沉默；无日期的来源不能说成“今天刚发生”。分享围绕读到的一件具体事情自然展开，避免新闻播报、摘要列表和固定问题结尾。未读过的视频、私人活动或体验不作亲历描述。

没有更改搜索/生成预算、持久化格式、角色隔离、长期记忆审核和工具授权。资料仍是不可信参考，模型不能借此更改设置或创建任务。

## 检查边界

这批提示词改进不等于已经证明真实模型对话质量提升。没有为文案增加逐字断言或重复测试矩阵，也没有调用收费模型。代码构建、推送链路检查和实际聊天反馈由本批统一交付记录说明。
