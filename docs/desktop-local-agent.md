# 电脑本地 Agent

从 0.7.19 起，电脑端与 DSH Web 的使用方式一致：启动一个本机程序，浏览器直接进入本机 CA；会话、模型凭据、角色、工具状态和工作区访问均由这台电脑上的 Go Core 管理。它不是云端服务的“已绑定执行器”。

2026-11-21 复核：本地运行方式已实现，但默认目录回退、异常退出恢复、模型配置的后台用途及读取/写入版本信息仍有待补齐的链路，详见[当前项目评估](project-assessment-2026-11-21.md)。使用远程模型仍需网络连接。

## 打开即用

Windows 构建产物名为 `chat-agent-desktop.exe`。文件名会自动启用桌面模式；也可用普通服务程序显式传 `-desktop`。

```powershell
.\chat-agent-desktop.exe
```

程序默认只监听 `127.0.0.1:8765`，生成并持久保存本机访问令牌，然后打开默认浏览器。令牌只放在 URL fragment 中交给页面，页面取走后立刻清除地址栏；不会输出到终端，也不会发送给云端。

- 数据目录：系统用户配置目录下的 `chat-agent/desktop`。
- 默认工作区：用户的 `Documents`；不存在时使用用户目录。可用 `-workspace` 指定其他目录。
- 模型：没有环境配置时仍能打开界面；在设置中添加兼容 OpenAI 的 API 后即可真实对话。API Key 只保存在本机数据目录。
- Agent loop：与服务器版共用 CA Harness，默认持续到模型给出最终回复、用户取消或超时，不使用短轮次上限伪装循环。

## 本机工具边界

本机工作区无需按会话绑定或手动打开。模型可以列目录、读取、搜索和请求分享文件；写文件使用读后 hash 校验和同目录原子替换，并且每次仍需用户批准。

Windows 当前没有已验证的强制 shell 沙箱，因此桌面模式不会把任意 PowerShell/cmd 直接交给模型。固定动作与旧远程执行协议仍可用，但不能冒充安全沙箱。后续只有在强制隔离后端可验证时才开放自由命令编排；不可用时继续明确拒绝。

## 与云端的关系

电脑本地端和云端是两个完整运行时：

- 本地端：电脑工作区、开发/学习任务、本机模型凭据与本机会话。
- 云端：手机随时访问、主动陪伴、提醒、QQ 等 IM 和服务器侧能力。
- `local-agent`：仅在用户需要云端额外调用某台电脑时启用，不是使用电脑端的前置步骤。

0.7.19 不会暗中同步两端历史。后续跨端接续应建立显式的会话/产物同步契约，保留来源、受众、operation 和授权信息；“共享获准长期记忆”也不等于自动复制全部聊天或文件。
