# 0.20.0 发布记录

2026-11-05。Generative UI 首版与电脑网页工作台已实现，正在准备部署与 Android 更新通道。Android 为 **0.20.0-debug / versionCode 17**，延续原包名、签名及设备身份。

模型可以在回答中生成单选、短填空、折线/正弦波、二维矢量四种组件。选择、输入和滑块只修改本地状态；答题需明确提交，反馈沿用既有队列和模型/思考选择。系统校验原始消息哈希、完成回合、真实选项/字段及有效上下文，答案回合仅开放只读工具。旧流式入口不能绕过这些约束，不改变 transcript/turns v1/v2。

电脑网页增加会话标题筛选与可收起的互动工作台。宽屏为第三栏，中屏覆盖层，手机全屏；展开移动同一组件节点，刷新保留局部输入。浏览器继续通过已选定的 SSH 隧道接入；没有新增服务器入口、桌面运行时、SSH 启动器或公网 HTTPS。图片沿用已有放大弹窗。使用命令见[电脑端说明](desktop-web-plan.md)。

## 关键验证

- Go：TestProtocolBoundaries、TestInteractiveFeedbackLifecycle、TestImageChatLifecycle、TestDurableTurnQueue 通过；构建和 vet 通过。覆盖错误来源、哈希、跨会话、畸形保留字段、排队过期、只读工具、普通消息隔离与同 ID 去重。
- 原生 JS 协议例子：四类型、长围栏、重复 ID/键、原型字段、未知/半份/超限声明与非有限数均按契约通过或回退。
- 隔离 demo 浏览器：四组件、历史刷新后的填空/选项/滑块/焦点、同实例展开、草稿保护、模拟响应丢失后同 ID 确认；服务端最终只保留一轮答案反馈。1440 桌面与 390 手机视口、深浅主题检查通过，滑块零请求、零真实模型调用。
- Android 离线构建通过。尚未安装真机、验证软键盘、真实模型选组件的质量、桌面 PWA 安装或生产浏览器设备审批。

首次挂载、刷新与重连只读，不补交答案。过期组件不能继续提交；未提交的局部答案不跨设备同步，刷新页面可能丢失。历史回看不代表当前有效上下文；目前最多保留 64 个局部组件状态。
