## 登录与语音稳定性

登录恢复和每次主动连接都带有认证代次，旧网络请求可以取消，连接初始化串行推进。旧结果或旧 401 不能清除新连接的凭据；退出登录后，晚到的保存回复不能重新打开聊天界面。认证 API 读取也检查代次与令牌归属，过期回调被忽略。

语音的会话清理会解除本页等待状态。原生识别期间即使桥接关闭，也保持“识别仍在系统界面中”的状态，直到系统回调完成，避免后续识别请求接收旧结果。退出会取消待回传结果；识别成功仍只回到草稿，确认后发送。

本次用户明确暂时没有真机，先开发发布。因此 **0.12.1 的工程修复完成，真机麦克风、设备网络和实际生命周期验收仍待完成**；模拟器和离线检查不能替代这些项目。

## 自然交流

由同一次 LLM 回应判断倾听、闲聊和共同解决问题，不增加显式模式、关键词意图分类、每轮情绪分析或额外的规划模型请求。策略要求关注当前具体内容，问题可选，允许简短反应或结束；不因活动关联或记忆存在就把用户拉回旧话题。

当前纠正直接支配本轮回应，是否持久化仍取决于用户意愿与实际工具成功。摘要沿用已有触发条件和调用方式，新增保留当前话题、明确未完问题和计划/结果区分的要求，不为本版主动增加摘要调用。

这些是行为指引与上下文改善，不是逐句自然表达保证；继续按实际反馈调整。

## 相关记忆与共同经历

新增自有 `internal/retrieval` 词面排序：中文双字片段、其他文字的完整词边界、套话过滤和当前候选集的词频权重，再按更新时间、ID 排序。事件时间仅影响已相关记录的同分排序，不能把无关事件变成相关事件。套话过滤用于检索，不决定工具、对话方式或用户授权。

自动参考最多四条已审核事实、三条 open/resolved 事件、两条相关活动；与当前显式关联活动、偏好及元信息共用 **16 KiB** JSON 预算。轮流选择不同来源，装不下的完整条目不注入，不截断事实或进展后当作完整记录。极端情况下当前关联活动只保留标识、版本、标题、状态及省略标记，可通过读取工具取得完整内容。无关聊天、纯套话或空自动查询不会靠“最近”补入旧事。

自动参考移除原始来源引文、会话来源标识和冗长合并追踪；后台保存的来源不变。事实候选不作为已知事实；事件仍仅 open/resolved；活动保留 active/paused/completed 状态，不改变计划、审核或绑定。

`shared_activity_open` 的 `action=list` 新增可选 `query`：只读检索最多八条，查询时可返回匹配活动的完整目标和进展，总结果受大小限制；空查询仅列最近记录的标识、版本、标题和状态。`query` 不能与修改操作混用。模型可看完旧进展后直接聊天，不必先恢复暂停活动。

事实/事件管理工具共用检索规则；显式空查询仍可查看最近记录，候选管理保留原筛选方式。纠正、遗忘和来源追溯沿用现有版本及上下文屏蔽机制。原聊天、导出和备份副本不会随单条记忆删除；事件或活动里独立保存的同一信息也需要分别更正，单条事实遗忘不会静默改写其他记录。

仍是词面检索，没有同义词语义理解、向量模型或长期访问频率记录。数据结构不变，现有 JSON/JSONL 可继续读取。
