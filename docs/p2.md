# P2 角色、记忆与上下文交付记录

日期：2026-10-26。独立实现，保持 Go 标准库与零第三方运行依赖；本阶段没有委派子代理。

此文为 P2 阶段记录，待办、提醒和可选联网能力的增量见 [P3 报告](p3.md)。

## 本轮实现

- 初始化“小伴 / companion”和“计划伙伴 / planner”工作区，分离 Persona、Rules、Profile 和 Markdown Skills。
- 每个会话持久化且固定绑定角色，切换角色创建新会话；旧 P1 会话默认归属 companion。
- 角色文档可在 PWA 编辑，Skills 可查看并由 `skill_load` 按需读取；不运行技能代码，不扩展工具权限。
- `memory_search` 只返回当前角色的已审核事实；`memory_write` 只能提出待审核候选，不能指定其他角色、自动批准、改写或删除已审核事实。
- PWA 记忆管理支持候选审核、手动添加、纠正、删除和 Markdown 导出，编辑与删除通过 revision 拒绝旧页面的覆盖。
- 新会话按当前消息检索相关已审核记忆，作为明确标注的参考数据提供给模型；角色与记忆工具均由服务器绑定作用域。
- 手动/自动上下文压缩，保留最近回合、完整原始日志，以及持久化摘要；失败、截断或取消的摘要不替换有效上下文。

## 存储选择与原规格差异

原始规格推荐 SQLite/FTS5；Go 标准库不提供 SQLite 驱动。本轮按后续确立的零依赖方向，使用每角色版本化 JSON 快照和中文双字/英文关键词匹配。**没有实现 SQLite、FTS5 或向量检索。**

记忆写入使用同目录临时文件、文件 Sync 和替换，成功后才发布到内存。删除从当前 JSON 快照移除内容，不保留旧事实的应用内版本；既有会话、摘要、已导出文件和备份不受影响。没有声称能安全擦除底层磁盘或通过断电恢复验收。

单个角色最多 500 条记忆、每条 4096 字节，快照最多 4 MiB。单份角色文档/Skill 最多 16 KiB，每个角色最多 16 个 Skills。记忆存储使用实例锁；异常退出后的锁不自动抢占。

## API 增量

全部接口沿用 Bearer 鉴权、禁止缓存与来源检查。

| 接口 | 行为 |
| --- | --- |
| `GET /api/roles` | 角色和 Skill 索引 |
| `GET /api/roles/{id}` | 当前角色的 Markdown 配置与 Skills |
| `PATCH /api/roles/{id}` | `file` 为 IDENTITY.md / RULES.md / PROFILE.md，`content` 为新内容；每次仅更新一份文档 |
| `POST /api/sessions` | 可传 `{"role_id":"planner"}`；不传时为 companion |
| `GET /api/sessions/{id}/messages` | 增加不可变 `role_id` 与可选 `summary` |
| `GET /api/memory?role_id=...` | 本角色的候选和已审核条目，支持 status/q 管理过滤 |
| `POST /api/memory?role_id=...` | 手动添加，默认 pending；用户可显式选择 approved |
| `PATCH /api/memory/{id}?role_id=...` | content/status 与当前 revision，跨角色 ID 返回 404，旧 revision 返回 409 |
| `DELETE /api/memory/{id}?role_id=...&revision=...` | 删除当前版本记忆 |
| `GET /api/memory/export?role_id=...` | 按审核状态分组导出 Markdown |
| `POST /api/sessions/{id}/compact` | 整理较早上下文，返回 changed 和 summary |

未开放任何模型直接执行内部工具的 HTTP 接口。角色设置接口只允许固定文件名，读取通过 `os.OpenRoot` 约束在工作区内，拒绝写入符号链接角色/文档。

## 上下文压缩策略

默认有效历史 JSON 超过 64 KiB 时尝试压缩，保留最近 4 个用户回合，从完整工具边界切分。字节阈值是本地历史触发条件，不是模型上下文 token 计数，也不包含角色提示等所有请求开销。

摘要使用同一模型的一次无工具请求，包含上次摘要与新覆盖的原始记录。它与整个当前运行共享超时，不重试；因此开启压缩可能增加一次付费请求。摘要输入最多 256 KiB，输出不得超过 16 KiB；仅完成且未截断的结果可以提交。

摘要只影响有效请求上下文，不删聊天记录、不生成长期记忆。重置会话清除摘要和有效对话，仍保留日志和独立角色记忆。演示摘要是标注过的固定摘录，不作为真实语义摘要质量证明。
