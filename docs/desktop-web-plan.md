# 电脑端网页使用与工作台方案

2026-11-05。状态：**0.20.0 桌面工作台已实现**，见[发布记录](release-0.20.md)。这是 [Generative UI v0.1](generative-ui-v0.1.md) 的一部分。浏览器继续沿用 SSH 隧道与现有应用鉴权；未配置公网 HTTPS 或本机启动器。

## 1. 产品形态

采用同一个 chat-agent Web/PWA，提供类 DSH Web 的电脑工作台体验：会话导航、持续聊天和可展开的结果区。继续使用 Go 服务、原生网页、服务器端模型密钥及现有设备白名单；不另做 Rust、Electron、React 客户端或第二套会话数据库。

这里借鉴的是网页工作区的组织方式。首版结果区只查看本会话的互动组件和既有图片，不引入远程终端、任意服务器文件浏览、Shell、代码执行或电脑控制权限。

```text
┌──────────────────┬────────────────────────────┬────────────────────┐
│ 角色与会话        │ 模型 / 连接状态 / 会话标题   │ 互动工作台          │
│ 新会话            │                            │ 当前题目、曲线、矢量 │
│ 标题快速筛选      │ 聊天、图片、工具结果、互动卡 │ 放大 / 收回 / 重置   │
│ 最近会话          │                            │                    │
│ 陪伴与工具        │ 输入框、图片、思考、发送/停 │ 无组件时收起        │
└──────────────────┴────────────────────────────┴────────────────────┘
```

0.20 在原有导航、聊天、模型/思考与图片上增加第三栏、会话标题筛选及组件工作台。图片继续使用现有放大查看弹窗，首版工作台主要承载四种互动组件。

## 2. 当前可采用的连接方案

现有服务器有 `127.0.0.1:9991` 的 HTTP 入口和面向 Android 的 PocketWire `9992` 入口。普通浏览器不能直接说自定义 TCP 协议，也不能把 pocket:// 当网页打开。暂时没有域名/证书时，电脑沿用用户已选定的 SSH 隧道。

已有项目隧道脚本 `deploy/Open-Tunnel.ps1`（默认本机 19991），可继续使用原端口与浏览器 origin，避免重新创建设备身份。它是前台 SSH 转发助手，不会自动打开浏览器或创建后台任务。运行后打开 http://127.0.0.1:19991。

首次连接也可在有现成 SSH 访问权限的电脑 PowerShell/终端运行以下等效命令（示例端口 18080）：

```powershell
ssh -N -T -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=3 -L 127.0.0.1:18080:127.0.0.1:9991 root@47.117.40.74
```

保持该终端运行，在 Edge/Chrome 打开 [http://127.0.0.1:18080](http://127.0.0.1:18080)。18080 是电脑本地端口，不需要增加云服务器安全组准入；显式只绑定 127.0.0.1，不向同局域网其他设备开放。若端口已占用，选另一本机固定端口并同步使用对应 URL。

链路为：

```text
电脑浏览器 → 本机回环 HTTP 18080 → SSH 加密隧道
          → 服务器回环 HTTP 9991 → 现有 Agent API → HTTPS 模型服务
```

端口转发参数和本机绑定依据 [OpenSSH 手册](https://man.openbsd.org/ssh.1)。回环页面可成为安全上下文，供 WebCrypto 等功能使用，见 [MDN Secure Contexts](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Secure_Contexts)。实施时仍须检查 `isSecureContext`、IndexedDB 和 crypto.subtle 是否在实际浏览器可用。

首次使用网页设备身份注册，由现有管理员核对并批准；SSH 成功不等于跳过应用鉴权。浏览器通过 WebCrypto/IndexedDB 保留本机密钥，不把 SSH 私钥或模型 API Key 放进页面。正常续签自动完成，退出与撤销沿用现有机制。

固定使用同一浏览器配置与本地 origin。更换 127.0.0.1/localhost、端口、隐私模式或清空站点数据可能创建新设备身份，需要重新批准；不能承诺本机存储清理后仍记得设备。

## 3. 桌面布局与互动工作台

| 视口 | 导航与聊天 | 工作台 |
| --- | --- | --- |
| ≥1200 px | 约 260 px 会话栏，聊天保持适宜阅读宽度 | 默认收起；打开后约 320–420 px，可收回，不压成窄列 |
| 761–1199 px | 保留现有侧栏/抽屉适配 | 侧滑覆盖层或独立弹层，避免强行三栏 |
| ≤760 px | 继续使用手机抽屉和底部输入框 | 全屏/大弹窗，仍是同一个组件实例 |

右栏仅在用户点击“展开”或选定组件后出现，不抢焦点、不因每次模型输出自动弹出。聊天卡片与工作台共用同一个 State Controller；优先移动原组件节点，聊天位置保留“正在工作台查看”的占位。收回时恢复原位和焦点，不能复制出两个会分别提交答案的表单。

工作台可显示：当前题目、填空、采样曲线、正弦波本地滑块、矢量图，以及现有会话图片的放大视图。只列已保存的本会话展示项，不枚举服务器目录；不把未读工具结果或未完成声明变成可执行面板。

聊天仍是唯一消息源。工作台内的“提交答案”沿用主规范的源校验、只读反馈、队列和未知状态确认，不另连模型；已有输入框草稿时不覆盖。拖动滑块、切换视图、缩放图片或展开工作台不调用模型。

## 4. 电脑操作与状态

- 模型、思考、图片、停止/排队、记忆/人设审核及活动入口保持同一套行为与授权。浏览器不走 Android 原生桥，不显示 APK 更新、Android 语音识别或常驻服务按钮。
- 会话快速筛选首版仅过滤已经取回的标题与角色，不宣传为服务端全文检索。Enter/Shift+Enter 沿用现有发送/换行；快捷键不覆盖浏览器地址栏、新窗口等保留操作。
- 用户上滚或在互动区输入时保留位置与焦点；底部有新消息只提示“回到最新”，不把视图抢回去。窗口 resize、工作台展开不清空草稿。
- 隧道断开显示连接状态，保留本地可见草稿；恢复时只查状态，不重发消息、模型请求或组件动作。重启隧道须由用户/后续本机启动器管理，网页不持有 SSH 登录材料。
- 当前 SW 缓存主要是静态壳，API 不缓存。隧道关闭后不保证能读取完整历史或继续聊天；桌面关闭窗口后也不承诺后台通知。现有 Android 常驻接收是独立渠道，不能因 PWA 安装就推断电脑也具备。
- 多端访问共用服务器记录，但未提交的桌面表单局部状态不跨设备同步；已提交内容仍通过服务器历史和队列恢复。

## 5. PWA、启动便利与后续直连

第一阶段用浏览器标签页即可。浏览器在符合条件并提供安装入口时，可以安装为独立 PWA 窗口；以实际安装能力为准，不承诺所有电脑/策略环境都有相同入口。

后续可加一个很小的本机启动器/快捷方式：核对本地端口、建立指定 SSH 转发、打开固定 URL，关闭时只停止自己创建的隧道进程。它不打包另一套 Agent 服务，不读取无关 SSH 配置或自动改系统代理；启动器与工作台可以分开交付。本次未实现启动器，不创建开机任务或本机后台进程。

有稳定域名与有效证书后，再考虑“浏览器 → HTTPS 反向代理 → 127.0.0.1:9991”。模型 Key、设备审批与接口鉴权保持服务端。公网 HTTP 与关闭证书校验不作为替代方案；浏览器纯前端实现 PocketWire 也不列为首版任务。

HTTPS 需要域名、证书和入口端口的具体配置；届时依据实际准入选择，不默认占用 443 或改变现有 9992。长期使用可单独设计仅允许指定转发的 SSH 用户；本文不自动修改服务器 sshd、用户或防火墙。

## 6. 实施与验收

与 Generative UI 首版共用开发批次：先把单栏卡片/状态/反馈做好，再增加电脑展开工作台；浏览器接入不依赖后者完成。新增桌面模块时同步 embed、SW 和资源允许列表，普通聊天在工作台模块失败时仍可用。

最小验收只有两条，合并到主规范四个流程中，不另做浏览器版本矩阵：

1. 一台电脑通过回环隧道打开页面、设备鉴权、正常聊天/图片/互动；断开恢复后没有重复提交。若只做了隔离 demo，就只能记录该范围，不能称为已验证生产隧道或真实模型。
2. 一个宽桌面和一个窄视口中，展开/收回同一组件，输入、焦点和 request_id 保持；工作台无横向溢出，纯黑/浅色及键盘操作可用。手机复用主规范的视口检查。

交付时分别列明：当前浏览器接入、桌面布局实现、PWA 实际安装、SSH 便利启动器、HTTPS 直连。不要把这些状态合并成一个笼统的“电脑端已完成”。
