# 0.17.0 发布记录

2026-11-04。作息与共同话题漏斗已部署到现有服务器，Android 更新通道已发布 0.17.0-debug / versionCode 14。功能与边界见[共同话题说明](topics-0.17.md)。

## 行为

共同话题保持默认关闭；需用户显式开启并填写公开兴趣查询，才会在持久化的随机时段执行。每次最多一次搜索、五条候选、两篇正文和一次模型决策，可选择不分享。跨角色每天最多三次尝试、至少三小时间隔和未读克制继续生效，同时共享关怀的角色额度、安静时段和暂停设置。

保留 ecnu-max、ecnu-rerank、摘要模型 ecnu-plus、设备白名单、加密入口和原配置，没有改动无关服务或端口。后台能处理获准的采集，但可靠手机后台推送仍未实现。
