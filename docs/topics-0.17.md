## 使用与行为

侧栏“共同话题”提供独立开关、公开兴趣查询、每日时间窗口、1–2 次唤醒机会、每日采集概率和额度。默认窗口 09:00–21:00、每天两次机会、70% 的每日采集概率。查询最多五项，每项最多 80 字；这些查询会发送给公开搜索引擎，不自动从私人记忆提取搜索词。

在开启后，服务端每 30 秒检查计划，即使应用关闭也能执行已获准的采集。手机可靠后台推送仍未实现，重新打开“分享给你”查看实际分享；通知原有机制没有被扩展到这些记录。

- 每个角色按服务端用户时区持久化当天的随机时刻和是否采集的决定；改变设置、删除记录或重启不重抽当天机会。
- 初次创建计划时已经错过的时刻直接过期；运行延误超过十分钟不再执行，不补发历史机会。
- 每次最多一次公开搜索请求、五条候选、两次正文读取、一次无工具模型决策。沿用 HTTPS、公共地址检查、固定已校验 IP、体积/时长限制和禁止内网重定向的网络边界。
- 读取正文后，由 LLM 决定分享一条或零条；不增加付费分类/重排调用。正文不可读时不把搜索摘要冒充正文，也不会继续扩展抓取。
- 共同话题的发现尝试每天全用户最多三次，跨角色共享；至少间隔三小时。有未读的已准备话题或正在执行的采集时不再启动新一轮。
- 同时沿用关怀设置中的角色每日尝试额度、安静时段、暂停和更长的间隔。无需开启普通每日问候，但其默认每日额度 1 也会限制共同话题。失败、沉默或用户删除记录不返还已预留额度。
- 如果生成期间更改话题设置或暂停关怀，结果不会继续发布。进程中断记录为 interrupted，不自动重放模型或采集操作。

没有接 B 站 Cookie、扫码、评论、账号操作或平台风控机制；没有创建后台任意工具回合，也不写入长期记忆、人设或待办。

## 两个记录视图

“运行记录”展示计划、状态、实际搜索/读取/模型尝试计数和来源等事实，不保存模型隐藏推理或完整网页正文。“分享给你”只展示已经选中并准备好的文本及真实读取过的来源。未命中、未形成分享、失败和过期不产生一条假分享。

计数在完整结算时保存；执行中、进程中断或用户取消时可能不完整，界面明确标为尚未完整结算，不把默认 0 当成未发生付费调用。这不替代 Harness 阶段 3 的持久请求/结果回执。

记录支持标记已读、取消未完成安排和删除。删除保留用于机会去重和额度结算的最小日期/计数，不等于退回模型费用；已有分享可能已经被用户复制或导出。

## 接口与模型工具

| 接口 | 行为 |
| --- | --- |
| GET /api/topics/settings?role_id= | 读取设置，不触发采集 |
| PATCH /api/topics/settings?role_id= | 带 revision 保存完整设置 |
| GET /api/topics?role_id= | 读取本角色记录，不触发采集或标记已读 |
| PATCH /api/topics/{id}?role_id= | 带 revision 标记 seen/canceled |
| DELETE /api/topics/{id}?role_id=&revision= | 删除记录，保留已结算额度和机会去重 |

模型使用 `topic_preferences` 读取和调整设置；开启需用户对持续公开话题采集的明确意愿，写入需真实本轮原文依据。只是提到兴趣不等于允许后台搜索。实际执行的搜索和抓取不通过模型工具循环扩大权限。

## 数据与检查

计划与记录位于 `<data>/topics/state.json`，独占实例锁，版本 1，原子替换写入；最多 1024 条运行记录，自动清理三十天前可清理的终态记录，未读分享保留。

共享关怀预算回执保存在 `<data>/life/state.json` 的 topic_attempts，首次预留话题尝试后写为版本 3；读取器兼容 v1/v2/v3，不使用话题时仍可写 v2。旧二进制不保证读取 v3，回退需处理该文件和新话题目录，不能只替换程序。会话 JSONL 没有迁移，Harness 阶段 3 仍未实施。

本批最小测试覆盖作息与删除/重启去重、跨角色上限、有限漏斗、模型零输出、不可读正文零模型调用、生成中暂停抑制发布、共享预算持久化和已有关怀/搜索边界。仅使用临时数据与模拟模型/网页，没有真实搜索或收费模型验收。另检查改动的 JS 模块语法，并构建服务端和 Android 开发包；实际构建结果以交付记录为准。
