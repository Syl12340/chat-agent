## 设备连接

设备生成自己的 P-256 签名密钥，公钥 DER 的 SHA-256 指纹作为设备 ID。Android 私钥位于 Android Keystore，按实际服务器地址隔离，升级和本机代理端口变化不影响身份；不采集 IMEI、MAC 或 Android ID，不在每次聊天时弹出生物认证。

首次连接登记为 pending，管理员核对公开指纹并加入白名单后才能登录。服务器发出 90 秒、一次性的 challenge，绑定服务实例、设备 ID、随机挑战及到期时间，设备签名后取得 20 分钟会话。会话续期自动重新完成 challenge。白名单每次请求检查，撤销后拒绝后续请求；已执行或已开始的请求不会被追回。

只在服务器明确返回未授权、处理器尚未执行时续期并重试该请求一次。网络结果不确定、模型或工具执行失败不会因此自动重试。退出使本次会话失效，并保留设备密钥和白名单；重新连接无需重新注册审批。Android 退出标记按服务器保存，重新打开不会立即替用户登录。

浏览器使用 WebCrypto 与 IndexedDB 保存不可导出的签名私钥，需要 HTTPS 或 localhost 安全环境。浏览器存储丢失/卸载应用/密钥丢失会产生新身份，需重新批准；这不是硬件证明或设备完整性认证。

原 `CHAT_ACCESS_TOKEN` 保留为兼容的高权限维护入口，具备管理权限；正常设备连接不会读取、持久保存或自动回退到它。模型 API Key 仍只在服务器。设备会话在网页内存中使用，Android 更新器仅接受短期设备会话，过期时请求网页重新鉴权；不使用旧的管理员口令代替白名单。

## 管理与接口

在“连接信息 → 设备管理”里，获准的管理员设备可批准或撤销其他设备。新批准设备默认不授予管理员身份；首台已通过 ADB 配对的用户手机由现有服务器维护身份登记为管理设备。root 维护入口仍可用于丢失管理员设备后的恢复。

| 接口 | 用途 |
| --- | --- |
| POST /api/device/register | 公钥登记，无自动授权 |
| POST /api/device/challenge | 仅为获准设备签发一次性挑战 |
| POST /api/device/verify | 验签并签发短期会话 |
| POST /api/device/logout | 注销当前设备会话 |
| GET /api/devices | 管理员查看设备名单 |
| PATCH /api/devices/{id} | 管理员按 revision 批准/撤销，可显式设置 admin |

记录位于 `<data>/devices/state.json`，存公钥、公开指纹、名称、状态、版本与权限；有独占实例锁。挑战和会话令牌哈希只在内存，服务重启后设备需自动重新证明身份。最多 512 条记录，已撤销记录仍计入；匿名请求、挑战、会话数量有限制。同一反向代理下的设备共享按来源地址计的限流。

## 界面

按 Google 当前 [Material 3 Expressive](https://m3.material.io/) 设计方向重做语义色彩、字级、圆角容器、胶囊操作、导航选中态、聊天输入区和设备连接页；覆盖记忆、事件、活动、关怀、设置及音频控件。支持深色模式、键盘焦点、减少动态效果偏好和移动端底部弹层；主要按钮采用 48px 触控区域。

Android 外壳使用匹配的紫色、表面色和胶囊按钮，触控目标至少 48dp。沿用平台控件和原生网页，不引入 Compose/Material 组件依赖，因此是自有样式实现，未声称完整复现官方组件库。
