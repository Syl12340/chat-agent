# P3 待办、提醒与可选联网交付记录

日期：2026-10-26。独立实现，仍只使用 Go 标准库；没有委派子代理。

## 完成范围

- 按角色隔离的待办添加、列表、完成、重新打开、删除。
- 一次性提醒创建、列表、到期收件箱、确认收到、取消、删除。
- 服务端每秒推进到期状态，写入成功后才发布；重启后补记过期提醒，已到期、已确认和已取消项目不重新触发。
- 创建请求持久化去重键；有效同名待办、同名同时间提醒合并，保留有界重试别名。记录更新使用 revision，跨角色 ID 返回 404。
- 工具 todo_add/list/complete、reminder_add/list/cancel；模型没有删除任务或执行任意计划代码的工具。
- PWA 待办与提醒面板、到期计数、确认/取消和手机布局；继续使用已有 SSE 工具事件显示执行过程和错误。
- 可选 web_fetch / web_search，默认不注册，需要显式开启与配置。

## 提醒的实际交付方式

这是服务端持久化收件箱，不是后台 Web Push 或系统通知。页面关闭时服务端继续记录到期，用户重新打开后查看；页面打开时约每 15 秒刷新，也可手动刷新。没有周期提醒、邮件、外部消息发送、自动模型调用或 Shell 执行。

默认用户时区 Asia/Shanghai，可用 -timezone 调整。二进制嵌入 IANA 时区数据。提醒存储 UTC，工具输入必须带显式时区；手动输入按设备时区解释，列表按配置时区显示。创建时间允许最近一分钟内以及未来 366 天，便于当前时刻的提醒输入。

## API 与持久化

所有接口沿用单用户 Bearer 鉴权、来源检查和禁止缓存。

| 接口 | 行为 |
| --- | --- |
| GET /api/todos?role_id=... | 当前角色的待办 |
| POST /api/todos?role_id=... | title、idempotency_key |
| PATCH /api/todos/{id}?role_id=... | status 为 open/done，携带 revision |
| DELETE /api/todos/{id}?role_id=...&revision=... | 删除 |
| GET /api/reminders?role_id=... | 当前角色提醒，响应头给出调度写入状态 |
| POST /api/reminders?role_id=... | title、带时区的 due_at、idempotency_key |
| PATCH /api/reminders/{id}?role_id=... | 到期项目可 acknowledged，scheduled/due 可 canceled，携带 revision |
| DELETE /api/reminders/{id}?role_id=...&revision=... | 删除并停止后续到期处理 |

记录存于 tasks/state.json，使用实例锁、版本化 JSON、临时文件 Sync 后替换。每个角色最多 500 项，总计 2000 项，快照最多 4 MiB，标题最多 256 字节。去重键 8–128 个字母/数字/横线/下划线，每项最多 16 个别名；已使用键不能被另一项的同名去重路径抢占。任务删除也会移除其去重键记录，不提供删除之后的永久幂等保证。

模型工具列表最多返回 50 项并显式给出 truncated，网页工具返回有界内容。原有 4 次实际工具调用、4 个模型回合、30 秒运行期限和最多 4 个并发生成仍有效。

## 联网边界

- 仅显式 -enable-web；缺少白名单和搜索端点时拒绝开启。
- web_fetch 使用精确 DNS 域名白名单，仅 HTTPS/443；不接受 IP 字面量、凭据、URL fragment、通配符或重定向。
- DNS 结果全部检查；私有、回环、链路本地、云元数据常见范围、CGNAT、保留地址及受限 IPv6 转换范围被拒绝；任何混合私有结果都会阻止拨号。
- TCP 连接使用已检查的具体 IP，TLS 保持原域名校验，不跳过证书，不使用环境代理。
- 8 秒 HTTP 期限，最多读取 256 KiB，抓取文本最多 12 KiB；不执行网页脚本或浏览器渲染。
- 搜索端点为自定义 GET q / JSON results 协议，可选 Bearer 密钥，只返回最多 5 条安全 HTTPS 链接；没有内置厂商 API 适配。
- 搜索结果链接只做 URL 格式和协议筛选，不对所有结果额外查询 DNS；真正抓取仍须经过域名白名单和公开地址检查，不宣称所有外部链接目标都已验真。
- 搜索密钥不用于网页抓取或前端。内容标记为不可信参考，不能扩展服务端工具白名单。
