# 0.21.0 发布记录

2026-11-05。原计划 0.20.1 的参数记忆与 0.21 的渲染/UI 合并实现，统一为 **0.21.0 / Android 0.21.0-debug，versionCode 18**。代码、关键验证与服务器/Android 更新通道发布已完成；原包名、签名与设备身份保留。

## 交付内容

- Markdown：嵌套列表、只读任务项、表格、删除线、转义与长围栏；代码复制/折叠，闭合 JSON 块可切换树与源码。
- LaTeX：行内、独立公式、分式与矩阵等 KaTeX 支持的数学子集。本地固定 KaTeX 0.19.1，使用原生 MathML，无 CDN、字体下载或额外模型调用；保留源码复制与错误回退。
- 新只读结构：`table.data`、`chart.bar`、`diagram.flow`。加上原四组件共七类，Schema/Go/JS 校验与模型指引同步，答案仍只允许原单选/填空协议。
- 参数记忆：网页按服务器 origin/身份保存每个模型最后手选档位，切模型与新会话恢复；Android 新增原生偏好桥，按真实服务器/设备存储，避开每次启动随机回环端口。暂时回退不覆盖偏好，入队与重试保留冻结参数。
- UI：统一消息阅读、富文本、工具执行与队列样式；展开按钮可收回原组件，刷新复用富文本节点，JSON 树视图与公式不反复重建。

Go 仍为独立标准库运行时；唯一新增前端渲染依赖是固定版本 KaTeX，MIT 许可同时保留在源码和嵌入资产中。保持现有 CSP、设备白名单、图片/模型链路和 transcript/turns v1/v2，本批没有 Harness 新格式或数据迁移。

## 最小验证

- `TestProtocolBoundaries`：共用 Schema 七类型示例，补行宽、系列长度、节点引用错误；`TestInteractiveFeedbackLifecycle`：来源、只读工具、隔离及过期源拒绝通过。
- 原生 JS 检查：七类型、非法结构、偏好迁移、按模型恢复、身份隔离、临时回退、存储失效与模拟原生快照恢复通过。
- 隔离 demo 浏览器：3 个公式含分式/矩阵无错误，2 张表、只读任务和嵌套列表、JSON 树、三种新结构及原正弦图正常显示；刷新保持树/公式节点，工作台使用同一实例。非法输入和数学预算按预期回退，1440/390 视口及深浅主题无整页溢出。
- 复用旧答题流程：选择/填空/滑块/焦点保留、草稿保护、模拟丢失响应后的同 ID 确认通过；滑块零请求，未调用真实模型。
- Go 构建/vet、Android 离线构建通过。发布前核对原签名和更新包哈希。

没有真机安装/重启、软键盘或真实模型呈现质量验收。浏览器重载与参数持久化已检查，Android 原生桥已构建，不能据此标记实际手机重启已验。麦克风没有测试。

MathML 不可用的浏览器显示源码；单美元仅保守识别带明确数学语法的内容，普通价格保留。未实现完整 CommonMark/GFM/TeX、Mermaid 源码、代码语法高亮或跨设备偏好同步。流程图是有界固定布局，复杂关系可局部滚动并查看节点/连线列表。
