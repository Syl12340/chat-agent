# 0.22.0 陪伴接续、模型消息投影与网页界面收敛

2026-11-06。状态：**服务端已部署**。线上版本为 0.22.0 / `20261106-continuity-ui-01`；本次没有原生 Android 改动，更新通道仍为 0.21.2-debug / versionCode 20，现有包装兼容。

## 行为变化

- 上下文体积估算和 Provider 请求共用同一模型消息投影。最终回答的展示用 `reasoning_content` 继续保存在 transcript/turns 并可在界面查看，但不再计入下一轮模型上下文或因此提前触发摘要；带工具调用的 reasoning 仍按上游协议保留并回传。
- 当前消息有具体检索词时只用当前消息召回，不让旧话题覆盖换题。对“那后来呢”一类没有具体检索词的短接续，最多回看最近三条可见用户消息，取最近的具体主题召回已审核记忆、事件和活动；历史 floor 之前的内容、assistant 文本和 `chat_ui_response` 不参与。
- 共同话题决策增加最近三次已生成/已读分享，要求同时避免重复主题、开场、观察和问题。既有来源 URL 去重、未读限制、三小时间隔、每日额度、公开网页正文读取及零输出选择不变。

## 网页界面

- 保留 Go 内嵌原生 HTML/CSS/JavaScript 和 Android WebView 共用页面，不引入前端框架。桌面侧栏改成固定工作轨道，只有会话列表独立滚动；当前会话以细色条和低对比底色标记。
- 对话正文、欢迎建议和输入区统一到 860px 阅读列。assistant 回答保持无气泡正文，用户消息使用克制的右侧气泡；工具状态、思考正文和回答操作降低常驻视觉权重。
- 欢迎建议恢复短说明而不扩大成营销卡片；输入框使用紧凑控制区、明确焦点环和居中的“回到最新”；Markdown 表格表头固定，代码、公式和长文本的边距与圆角统一。
- 互动组件仍是同一个 DOM 实例：宽屏在稳定右侧工作台展开，中窄屏使用覆盖面板。手机端保留 16px 输入字号、安全区和完整抽屉；PWA 静态缓存升级为 `chat-shell-v28`。

这轮只借鉴 DSH 的固定工作区组织、DeepSeek 的低噪声对话面和 GPT 的阅读/输入层级，没有复制品牌资产、嵌入外部运行时或增加显式对话模式。公开 GPT 设计原则只用于“采用最小够用呈现、保留对话上下文、限制主操作数量”等界面判断。

这些变化不增加分类模型、模型调用、工具次数或持久格式。没有新增显式聊天模式、自动记忆写入或后台写权限。计划/实际、当前纠正、话题切换和少问问题仍由同一轮 LLM 结合现有历史与有来源参考处理。
