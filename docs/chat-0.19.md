# 0.19：图片、模型选择与聊天界面

2026-11-05。本批交付图像上传、每条消息的模型/思考强度选择，以及参考 ChatGPT / DeepSeek 阅读布局的界面调整。部署状态见[发布记录](release-0.19.md)。没有引入前端框架、外部 Agent 运行时或第三方 Go 模块。

## 使用

顶部选择 ECNU Max 或 ECNU Plus，输入框选择“关闭思考 / 中 / 高 / 超高”。选择只影响后续发送，角色、已有对话和后台关怀/话题模型不随菜单切换。默认保留 ecnu-max，思考关闭。服务器提供允许列表，客户端不能填写任意模型、接口地址或 API Key。

图片通过输入框“＋”、粘贴或拖放添加，每条最多三张 JPEG/PNG。选择后只在本机预览，可移除；点击发送后才上传并交给所选模型。可以只发图片，不补写假用户文本。浏览器把不超过 12 MiB、4000 万像素的原图缩至最长边 1600 像素，最终每张不超过 4 MiB。服务器独立验证真实 JPEG/PNG，拒绝超出 4096 边长或 1200 万像素，并重新编码去除 EXIF 等附加元数据；SVG、GIF、HEIC 和远程图片 URL 不在首版范围。

Android 需要 **0.19.0-debug / versionCode 16**，使用系统文件选择器，不申请整个相册/文件访问权限。只允许本轮用户选中的 content URI，页面、来源或服务器变化后回收选择回调；旧客户端明确提示升级，不显示无响应的上传入口。

历史图片由已鉴权接口懒加载为本地 blob URL，不把 token 放进链接。最多保留 29 个历史预览和 3 个草稿 URL；切换会话、角色或退出释放缓存。点击图片放大查看。大图存储在服务器的对应会话，不自动成为长期记忆。纯图片回合只提供只读工具，图片中的文字不能成为保存数据或修改设置的授权。

界面保留所有角色、记忆、共同活动、关怀和设备入口，收进侧栏“陪伴与工具”。用户消息右侧紧凑显示，助手回答连续排版，代码块可横向滚动与复制；新增复制回答、回到最新消息，保留停止、排队、撤回及未知提交确认。

## 模型与思考参数

已在服务器内只读查询 `/models`，账号的对话模型为 ecnu-max / ecnu-plus；embedding、rerank、image、tts 不作为聊天选项。两模型的图像理解与思考参数依据[官方通用对话](https://developer.ecnu.edu.cn/vitepress/llm/api/completions.html)和[官方思考说明](https://developer.ecnu.edu.cn/vitepress/llm/thinking.html)。本次没有调用实际生成接口进行识图或思考质量验收。

| 界面档位 | ecnu-max | ecnu-plus |
| --- | --- | --- |
| 关闭 | thinking.type=disabled，无 effort | thinking.type=disabled，无 effort |
| 中 | enabled + low | enabled + low |
| 高 | enabled + high | enabled + medium |
| 超高 | enabled + max | enabled + xhigh |

思考档位控制请求参数，不能保证具体推理时长或回答质量。开启思考允许至少 120 秒的整轮预算，单次模型响应默认输出上限 4096，由 `POCKET_THINKING_MAX_OUTPUT` 在 128–16384 范围配置；普通聊天继续使用原超时和 `-max-output`。不增加自动重试、模型切换或额外分类请求，工具/模型步数上限保留。更高档位可能增加等待时间与 token 消耗。

只显示“思考或等待模型回应”等状态，不展示模型思考正文。工具调用要求的 reasoning_content 有界保存并按上游协议回传，网页历史与摘要会剔除，不当作用户输入、写入依据或聊天内容。没有工具调用的最终回复不保存思考正文。后台摘要、关怀和话题保持原路由与无工具生成边界，不继承输入框的档位。

## API 与存储

| 接口 | 行为 |
| --- | --- |
| GET `/api/chat/options` | 已鉴权模型允许列表及能力，不传凭据 |
| POST `/api/sessions/{id}/images` | 原始 JPEG/PNG body，返回 id/mime_type/size/width/height |
| GET `/api/sessions/{id}/images/{image}` | 已鉴权、会话绑定的规范化二进制，no-store |
| DELETE 同上 | 仅清理未被聊天/台账引用的上传；已引用返回 409 |
| POST `/api/sessions/{id}/turns` | 增加 model、thinking、image_ids；真实 content 可为空但必须有图 |

每条提交固化模型、思考档位和有序图片 ID；同 request_id 改参数返回 409，断网确认复用原参数，不重新上传已经拿到 ID 的图片。只有模型/档位相同、合计不超过三张图的相邻消息可合并执行。

`<data>/images` 保存规范化图片与角色/会话元数据，独占实例锁、临时目录原子发布、SHA-256 校验，文件 0600、目录 0700。单会话最多 64 张 / 64 MiB，全局最多 256 MiB、1024 个图片会话和 4096 张图片。只清理未发布的上传临时目录，不定时删除已发布草稿；上传结果丢失可能留下孤立图片，由整会话删除清理，仍计入配额。

每次模型请求只加载有效上下文中最新三张图片，更早的图以明确的临时占位说明替代；完整聊天及原图不因此删除，需要重新看旧图可再次发送。模型可依据之前已生成的文字描述，不能声称本次看到了被省略的图。DataURL/base64 只存在于本次模型请求内存，不落入会话、台账或普通日志；摘要不加载图片，已生成的文字描述可参与摘要。

删除整会话会清理图片。硬删最新一轮会原子移除该合并批次的全部台账行，并删除仅由此轮引用的图片；仍被其他消息引用的图及其他未发送草稿保留。删除会话不删除角色记忆/活动，也不能撤回模型服务已接收的数据、手机预览、用户导出或备份。

## 格式兼容与验收边界

读取兼容旧 transcript v1 / turns v1，未使用新字段的旧客户端仍可写 v1；新界面固化模型参数会使台账写 v2，含图或工具思考协议的 transcript 写 v2。这是现有日志的多模态扩展，**不是 Harness 阶段 3 的持久事件、回执和恢复实现**。3B/3C 仍待实施。

0.18 及更早二进制不能读取新 v2 文件。升级先做一致性备份，不在启动时批量改旧会话。发生新写入后不能仅切旧二进制降级，也不能直接还原旧备份覆盖新用户数据；须保留新现场，明确兼容转换与恢复方案。删除后的当前代保持版本，不偷偷降级格式。

本批只增加媒体生命周期、provider/会话协议、队列选项、完整 API 图片回合四个关键测试；另运行受影响的队列、删除和摘要最小回归。浏览器在独立 demo 中检查模型/档位、仅图发送、鉴权预览、复制入口及手机无横向溢出，浅色/深色截图已检查。Android 构建通过；没有真机文件选择器、软键盘、实际识图质量或真实思考耗时验收，不用 demo 回答冒充识图结果。
