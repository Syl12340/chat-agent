# P1 聊天服务交付记录

日期：2026-10-26。基于项目内运行时实现，未引入 Harness 或第三方运行依赖，也未委派子代理。

此文为 P1 阶段记录。角色、记忆和压缩的后续进展见 [P2 报告](p2.md)。

## 完成范围

- Go HTTP 服务，原生 PWA 资源通过 embed 嵌入二进制。
- 单用户 Bearer 访问口令，恒定时间比较；模型 API Key 保留在服务端。
- 创建/列出会话、读取历史、提交消息、SSE、取消、上下文重置。
- 手机抽屉、聊天气泡、可展开工具记录、基础安全 Markdown、刷新恢复、PWA manifest 和离线静态资源。
- 本地演示模式明确标注，与真实模型模式分离；演示和真实模式默认使用独立数据目录。
- 128 KiB JSON 请求限制、64 KiB 消息限制、同会话互斥、全局最多 4 个生成、模型回合/工具/输出/时间预算。
- API 响应禁止缓存，Service Worker 只缓存页面资源；跨站 API 来源校验、CSP、禁止页面嵌入和 MIME 嗅探。
- 正常关闭先取消和等待运行，再关闭会话和释放锁文件。

## API

除 `/healthz` 和静态页面外，下列接口均要求 `Authorization: Bearer <POCKET_ACCESS_TOKEN>`。

| 接口 | 行为 |
| --- | --- |
| `GET /api/status` | 模型名称、模式和响应期限，不返回凭据 |
| `GET /api/sessions` | 当前会话列表、标题与生成状态 |
| `POST /api/sessions` | 创建会话，返回 201 |
| `GET /api/sessions/{id}/messages` | 读取有效上下文和生成状态 |
| `POST /api/sessions/{id}/messages` | JSON `{"content":"消息"}`，返回 SSE |
| `POST /api/sessions/{id}/cancel` | 取消并等待运行结束，可重复调用 |
| `POST /api/sessions/{id}/reset` | 追加重置记录，保留原始日志；生成中返回 409 |
| `GET /healthz` | 公开存活检查，仅返回状态 |

SSE 事件：`ready`、`text_delta`、`tool_start`、`tool_result`，最后为 `done`、`canceled` 或 `error`。断开客户端连接也会取消对应模型请求。原始模型错误正文不发给网页。

## 实际边界

- 本机验证为 Windows 与 Chromium 手机视口，未在真实 Android 设备、真实模型 API 或 Linux 服务器上验收。
- 手机 HTTPS 安装体验、生产限流、代理部署、备份、长期资源占用和断电恢复尚未验收；当前没有公网发布。
- 页面仅支持基础 Markdown 子集；不渲染原始 HTML、图片、复杂表格或完整 CommonMark。
- 当前同一服务进程保留已打开的会话实例，正常关闭释放；异常退出后的锁和损坏记录需要人工处理。
- 取消后的未完成助手文本不持久化；重置有效上下文不等同于物理删除历史日志。
- 角色、Rules、Skills、长期记忆、SQLite/FTS5、上下文压缩和任务调度留给后续阶段。

运行入口和配置方式见 [README](../README.md)。真实模型需配置 `POCKET_BASE_URL`、`POCKET_API_KEY`、`POCKET_MODEL` 后去掉 `-demo`；访问口令使用独立的 `POCKET_ACCESS_TOKEN`。
